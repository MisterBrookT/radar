# Case: Generative UI weekly review

The first topic preset for Radar. It demonstrates the general engine; it is not the engine's boundary.

## Run

```bash
uv run python -m radar run --topic genui --week-ending YYYY-MM-DD --run-id UNIQUE-ID
```

Configure the Pi model routes, local English Piper and delivery account first; see [runtime setup](../../docs/pi-dgx.md). The [preset](../../topics/genui.json) owns source queries and the core/adjacent topic boundary. Research, narration, visual planning, review and delivery are project-run stages.

## First verified issue

**September 25–October 1, 2026** (current day partial). Two main lines:

1. **AUV-Bench:** aesthetic judgment does not reliably translate into successful UI repair/generation. [Primary paper](https://arxiv.org/abs/2609.34854).
2. **Native Angular A2UI rendering:** CopilotKit replaces its Lit-based integration with native Angular catalogs and supports Custom Elements. [PR #7504](https://github.com/CopilotKit/CopilotKit/pull/7504), [v1.75.1 release](https://github.com/CopilotKit/CopilotKit/releases/tag/v1.75.1). The [A2UI README](https://github.com/google/A2UI) is explicitly related context, not a separate headline.

The project produced a **157.26-second** English video with 43 aligned English/Chinese semantic units and original-source figures. Research, visuals and independent review workers exited successfully. Full decode, input/artifact hashes and actual-frame inspection passed. The standalone delivery API accepted caption and video once; the recipient subsequently watched and approved the case.

See [result.json](result.json) for the non-secret verification summary. Videos, downloaded figures/papers, speech caches, private receipts and other generated run artifacts are deliberately **not committed**. They are outputs of the project, not its source.
